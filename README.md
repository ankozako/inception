# Description
The goal of inception is to create an infrastructure using Docker, which launches several services (a=MariaDB, Wordpress, NGINX) that communicate with each other in a secure manner. Through the project we learn about containerization, services coordination with Docker Compose, volume management and system configuration.

# Project Description

## Virtual Machines vs Docker 

### Virtual Machines
A virtual machine (VM) is like a virtual computer inside a physical computer. It can have a different operating system (OS) from the physical host computer. It is convenient when one needs a testing environment (for example to test a new OS), or just needs to work on two different OS, it is possible with using just one physical machine. The VM environment is also isolated, so if the VM crashes, the host computer remains unaffected.   

### Docker
The Docker is a template contatining instructions for creating a container.
